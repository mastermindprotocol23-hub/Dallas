# Dallas Roofing Website

A high-performance, modern roofing contractor website built with pure HTML5, CSS3, and modern JavaScript with smooth parallax effects, before/after inspection slider, and automatic lead submission straight to your Gmail.

## 🚀 Features

- **GitHub Pages Ready**: `index.html` configured at the root for 1-click free hosting on GitHub Pages.
- **Automatic Instant Email Notifications**: All inspection requests submitted from the request box are automatically sent to `velorix.cloth@gmail.com`.
- **Zero Server Setup**: Powered by FormSubmit with fallback support for Web3Forms and direct POST.
- **Interactive Parallax & Micro-interactions**: Multi-layer hero depth, scroll-scrubbed text glow, and before/after roof restoration slider.
- **Mobile Responsive & Fast**: Optimized typography and layouts across mobile, tablet, and desktop screens.

## 🌐 How to Deploy to GitHub Pages (গিটহাবে আপলোড এবং লাইভ করার নিয়ম)

### Step 1: Push to GitHub (গিটহাবে পুশ করুন)
Open terminal/PowerShell in this folder and run:

```bash
git add .
git commit -m "Dallas Roofing website ready for GitHub Pages"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPOSITORY_NAME.git
git push -u origin main
```

*(Replace `YOUR_GITHUB_USERNAME` and `YOUR_REPOSITORY_NAME` with your actual GitHub username and repository name).*

### Step 2: Enable GitHub Pages (ফ্রি লাইভ সাইট চালু করুন)
1. Go to your repository on GitHub.
2. Click **Settings** (উপরে ডানদিকের মেনুতে).
3. On the left sidebar, click **Pages**.
4. Under **Build and deployment > Source**, select **Deploy from a branch**.
5. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
6. Wait 1-2 minutes! GitHub will generate your live website link (e.g., `https://username.github.io/repo-name/`).
